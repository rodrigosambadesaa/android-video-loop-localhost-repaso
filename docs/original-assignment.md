# Ejercicio histórico

Requisitos conservados del enunciado:

- arrancar Wampserver;
- copiar `video.mp4` a `C:\wamp\www\`;
- reproducir el vídeo en bucle al iniciar la interfaz;
- colocarlo en la zona superior, con 100 dp de alto;
- URL: `http://10.0.2.2/video.mp4`;
- declarar `android.permission.INTERNET`.

La reconstrucción actual añade únicamente los requisitos de seguridad y permisos propios de Android moderno.
